Drop your sample PDFs here so the tool can be calibrated and tested.

Use these names (or pass your own paths on the command line):

  redlined.pdf   -> YOUR marked-up PDF (architect's original drawing + your red redlines)
  revised.pdf    -> the architect's revised PDF that came back (changes baked in, usually black)

Optional, if you have more than one example, make subfolders:

  samples/
    example1/
      redlined.pdf
      revised.pdf
    example2/
      redlined.pdf
      revised.pdf

Notes:
- Both PDFs should be the same sheet/scale (a revision of the same drawing). Slight shifts are OK.
- Real files are only used locally on your machine. Nothing is uploaded.
